# Trading App - Android

## Setup
This project source code was generated by the Antigravity agent.

## Build Prerequisites
- Android Studio Iguana or newer (recommended)
- JDK 17 (embedded in Android Studio)

## How to Build and Run
1. **Open in Android Studio**:
   - Launch Android Studio.
   - Select **Open**.
   - Browse to `C:\Github_sync\trading-stack\android`.
   - Click **OK**.

2. **Sync Gradle**:
   - Android Studio will detect the build files (`build.gradle.kts`) and attempt to sync.
   - It will automatically download the required Gradle version and SDK components if missing.

3. **Run**:
   - Select an emulator (Pixel 3a API 34 recommended) or a physical device.
   - Click the **Run** (Green Play) button.

## Connection Details
- The app expects the Mobile BFF to be accessible via the Nginx Gateway on port 3000.
- `MainActivity.kt` uses `http://10.0.2.2:3000/api/mobile/v1/` which maps to `localhost:3000` on your host machine.
- If running on a physical device, ensure your phone and computer are on the same WiFi, and update `MainActivity.kt` with your computer's local IP (e.g., `http://192.168.1.x:3000/...`).

## Troubleshooting
- **"Connection Refused"**: Ensure Docker is running and the BFF container is up (`docker compose ps`).
- **"401 Unauthorized"**: Ensure the BFF has a valid Grafana Service Account Token mapped in the `.env` file (the agent scripts attempt to automate this).
