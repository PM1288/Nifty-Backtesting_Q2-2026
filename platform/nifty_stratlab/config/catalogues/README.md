# Hybrid strategy catalogues

This directory stores immutable source catalogues and their wave definitions. Do not edit a strategy threshold after seeing results; create a new catalogue version instead.

Validate and generate the 96 isolated worksets with `tools/setup_hybrid_catalogue.py`. The source catalogue is descriptive research input. A generated workset is not authorized for a full run until its entry detector and required D1/D2/D3 data dependencies have passed their gates.
