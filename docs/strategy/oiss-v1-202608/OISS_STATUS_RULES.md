# Status rules

Only governed statuses are emitted. D/F or absent required score → `DATA INSUFFICIENT`. Extreme extension → `NO CHASE`. Any remaining hard gate → `NO TRADE`. OFactor below 65 → `NO TRADE`. Strong opportunity without completed trigger → `WAIT FOR BREAKOUT` (long) or `WAIT FOR FAILED BOUNCE` (short). BUY/SELL requires A/B DQ, O≥75, X≥75, TQS≥78, R:R≥1.5 and every gate clear. Otherwise → `WATCH`.

Hard gates override TQS. Every row persists four explanations and rejection evidence.
