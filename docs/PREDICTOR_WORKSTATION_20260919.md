# Predictor workstation — 19 September 2026 IST

## Scope and status

Additive `/predictor` page, direct desktop top-bar link and mobile-navigation link.
Authenticated read-only APIs `/v1/predictor?day=YYYY-MM-DD` and
`/v1/predictor/evidence/:id`. Existing OIIS/MWHD, Paper Trading, Scalper V2,
collectors, notifications, authentication and order permissions are unchanged.
No order or notification is generated by the predictor.

The first release deliberately forecasts **same-session closing price from
morning information**, not an intraday high/low path or a guaranteed trade target.
It does not claim to implement every AI algorithm. Deployment evidence is appended
below after release. No live morning/EOD cycle has occurred since implementation:
it is Saturday locally. The recorded next session is 21 September.

## Algorithm review and choice

| Method | Decision | Reason / limitation |
|---|---|---|
| No-change forecast | Required benchmark | Learned models must demonstrate improvement over it. |
| Ridge regression | Implemented | Transparent regularised linear relationships; training-only standardisation. Fixed alpha 10, intercept unpenalised. |
| K-nearest-neighbour regression | Implemented as Similar-day matching | 25 equal-weight nearest daily opening contexts after training-only standardisation. Neighbour dates/returns exported. |
| Random forests / gradient boosting | Deferred challenger | Nonlinear models are plausible but require a versioned tuning/validation experiment, not a claim of superiority. |
| Logistic classification | Deferred | Would target direction separately; current probability is an empirical error-frequency estimate, not a fitted/calibrated classifier. |
| LSTM / Transformer | Not enabled | Current minute history is too short to justify high-capacity intraday models. |
| LLM/news price forecasts | Not enabled | No unsupported price generation; existing independent AI stock research remains intact. |

Official references reviewed:
- [Time-aware evaluation and lagged features](https://scikit-learn.org/stable/auto_examples/applications/plot_time_series_lagged_features.html)
- [Ridge regression](https://scikit-learn.org/stable/modules/linear_model.html#ridge-regression-and-classification)
- [Nearest-neighbour regression](https://scikit-learn.org/stable/modules/neighbors.html#nearest-neighbors-regression)
- [Probability evaluation](https://scikit-learn.org/stable/modules/calibration.html)

These references motivate methodology; they are not evidence that these models
predict NIFTY profitably. TypeScript implementations are deterministic and tested;
no new model package or external AI provider is needed.

## Data and eligibility

- Observed NIFTY daily coverage: 916 bars from 2023-01-09 to 2026-09-18.
  The bounded study loads the latest 850: 21 warm-up + 829 usable examples.
  At review time minute history covered only 14 recent NIFTY sessions (RELIANCE 16).
- Train from canonical `bars_1d`, NSE exact token, dates strictly before forecast
  session, at most 850 raw bars. Up to 500 valid examples train each model.
- Need at least 180 examples (120 initial + 60 walk-forward residual examples).
- Features: today's opening gap vs previous close; prior daily return; 5-/20-
  session close momentum; 20-session return standard deviation; prior high-low
  range divided by prior close. No future day high/low, OI or invented IV input.
- Invalid OHLC, nonpositive/nonfinite prices, >25% discontinuities and excessively
  sparse 21-bar windows are excluded. No raw values are silently adjusted.
  This is a conservative guard, not a complete corporate-action reconciliation.
- NIFTY token 99926000 was verified from canonical subscriptions.
- Stocks come only from the latest completed **same-day** OIIS run with
  `selected OR recommended OR auto_paper_selected`, and known-at capture time.
  This explicitly matches the existing UI selection concept; mere eligibility
  alone does not admit a stock.
- Reuse existing Home progression period anchors and gate operands. LONG:
  month open > previous-month close; latest > current-week open;
  latest > previous-week open; latest > today open. SHORT reverses comparisons.
  M−2 additionally requires M−1 and month open vs two-months-ago close.
  NIFTY is admitted independently. Hour/15m/5m gates are not required by this task.
- Fresh completed 1-minute bars provide exact opening and reference prices.
  Opening bar must begin at the calendar market open; most recent completed bar
  must be within three minutes. Previous daily session must be present.
  Missing candidates, gates, bars or sufficient training history skip publication.

## Forecast and evaluation contract

`morning-close-v1`: first qualifying capture between market-open +15 and +45
minutes (09:30–10:00 IST normally), one immutable forecast per day/symbol/model.
Closing return training target is `100*(close/open-1)`. Ridge/KNN convert predicted
return back to a close using today's first observed open. The live no-change
benchmark uses the saved morning reference price.

Forecasts share a cohort and save model parameters/neighbours, feature values,
raw training bars + SHA256, training cutoff, source/opening/reference timestamps,
OIIS identity and complete MWD gate evidence. PostgreSQL assigns actual publication
time; a past deadline cannot be bypassed by passing a forged timestamp. Update /
delete triggers protect forward forecasts and outcomes. Historical study records
are separately labelled and cannot be confused with forward forecasts.

Band: 10th–90th empirical quantiles of the last 60 chronological prediction errors,
added to the point estimate. Estimated probability above reference is the smoothed
fraction of these implied closing outcomes above the saved reference. **Neither is
intraday-calibrated or guaranteed.** A morning price has more information than the
daily-open training model; evaluate live performance separately before trusting it.

EOD evaluation starts 60 minutes after calendar close and waits for a valid same-day
daily OHLC. No LTP/adjacent-date fallback. Large reference discontinuities and >1%
opening mismatch remain unscored. First accepted EOD revision is frozen; later
source revisions are not silently rewritten into a better score.

Daily leaderboard: mean absolute closing-price error as % of saved reference,
direction correctness, empirical-band coverage, Brier score, matched sample count.
Only cohorts with all three model outcomes enter rankings. Flat benchmark direction
is a distinct state, not a correct up/down guess. Ranking is descriptive, not P/L.
Conditions: sign of 20-session trend; daily volatility above/below fixed 1.5%.
Small groups are not evidence of a durable edge or a causal relationship.

Historical lab: latest 60 valid sessions, each trained only on earlier rows. Uses
retained/revised daily prices, **not strict historical knowledge timestamps or
historical OIIS/MWD selection**. Never labelled as a historical trading portfolio.
Stocks gain studies when first eligible for live publication; NIFTY's study is
available immediately. No weekend stock list is passed off as Monday's selection.

## Operation, safety and performance

`startPredictorScheduler` launches compiled `scripts/predictorJob.js` in a separate
Node process 15 seconds after API startup and every five minutes. Memory cap 256MB,
270s process timeout, 240s transaction bound, transaction-scoped advisory lock.
No model fitting in the API event loop, GET handlers, pointer callbacks or browser.
No broker requests/new collector. Morning capture only; EOD and heartbeat outside
the window. Night/weekend NIFTY study runs once per date/version.

`PREDICTOR_ENABLED=false` disables new worker launches while retaining read APIs.
Status heartbeat older than 12 minutes is visibly delayed, not false green health.
API failure preserves previously hydrated client evidence with a refresh warning.
