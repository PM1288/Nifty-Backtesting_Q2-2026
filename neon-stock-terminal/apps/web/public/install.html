Install N50

iPhone or iPad
  1. Open N50 in Safari and tap Share. In the compact toolbar, open More first.
  2. Choose Add to Home Screen. If it is hidden, scroll down and choose Edit Actions.
  3. If shown, turn on Open as Web App, then tap Add.
  4. Launch N50 from the new Home Screen icon. Sign in if prompted.
Android

In Chrome, open the browser menu and choose Add to home screen or Install app. Choose Install when prompted.

Desktop

In Chrome or Edge, use the install icon in the address bar or the install option in the browser menu. In supported versions of Safari on Mac, choose File → Add to Dock.
