# Social Media UTM Links

All links in this file point to the live production app on `https://m.nifty50today.co.in`.

Use these as copy-ready templates. Replace only the placeholder tokens like `_channel_name_`, `_creator_name_`, `_subreddit_name_`, `_group_name_`, or `_thread_name_` before publishing.

## Rules

- Keep the production host exactly as `https://m.nifty50today.co.in`.
- Keep the `/n50/` app base path.
- Change placeholder values only.
- Keep UTM values lowercase and underscore-separated.
- Use a new `utm_id` when you need to track a new post or creative version.

## Validation checklist

- Open one tagged link in a clean browser session.
- Confirm the URL stays on `m.nifty50today.co.in`.
- Confirm the app stores attribution in `localStorage` under:
  - `n50.analytics.attribution.v1`
- Confirm Matomo receives the visit on the production site.
- Confirm the campaign fields match the chosen `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, and `utm_id`.
