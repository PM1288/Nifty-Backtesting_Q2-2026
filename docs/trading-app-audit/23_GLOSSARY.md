# Glossary

> Evidence basis: static source inspection generated 2026-08-23T11:30:04.012Z. Runtime behaviour is labelled separately. “UNVERIFIED” means the source alone cannot establish the runtime condition.

| Term | Repository-specific meaning |
| --- | --- |
| D0 | Entry trading session; not necessarily calendar day zero after timestamp conversion |
| D+5 / five-session | Five eligible trading sessions, not five calendar days |
| D+30 / thirty-session | Thirty eligible trading sessions unless a feature explicitly states calendar days |
| MFE | Maximum favourable excursion in the stated direction/window |
| MAE | Maximum adverse excursion in the stated direction/window |
| Booked | Governed execution result persisted as realised |
| Open actual | Current marked result on remaining execution quantity |
| Observed | Analytical path/target evidence; not automatically booked |
| Hypothetical | Counterfactual outcome under a stated rule |
| Simulated | Portfolio/capital model result |
| OIIS | Independent strategy family using opportunity/institutional/execution evidence as defined by its policy |
| Freshness | Age of the underlying source value, distinct from transport connectivity |
