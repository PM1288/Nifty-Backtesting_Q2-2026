# Hybrid Catalogue Limitations

- Catalogue prose such as “trend non-bearish”, “breadth stable”, “near support” and “volume confirms” is not executable until an objective versioned detector freezes its formula and threshold.
- Stock-only CSVs support D1 research after session-quality and corporate-action qualification. They do not independently satisfy D2 or D3 dependencies.
- The nine existing reference manifests retain their original native exits. The generated hybrid worksets override those exits for the requested comparable target-only study; an execution adapter still must enforce that override before a full run.
- RELIANCE smoke validation currently proves the 96 workload contracts and source presence. The nine golden fixtures additionally prove existing reference signal and next-bar-fill behavior. It is not a claim that all 96 entry detectors have run on RELIANCE.
- Probability is `NOT_CALIBRATED`; there is no broker-order authority.
