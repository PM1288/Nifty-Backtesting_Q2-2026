# OIIS Factor DOE Delivery — Version 1.0

## Purpose

This delivery converts the OIIS OFactor/XFactor research mandate into a governed, executable and reusable design of experiments. It also captures what the supplied legacy threshold and minute-profile bundles can and cannot presently establish.

## Current evidence decision

- Canonical O74 / XFactor Tier-B 76 / Tier-A 84 baseline: **not reproduced**.
- Legacy “49-factor” bundle: **49 aggregate O/X threshold configurations, not 49 independent factors**.
- Component-level factor importance: **not estimable from current lite bundles**, because event-level component scores and controlled perturbation trials are absent.
- FFactor: **undefined in authoritative supplied OIIS material; no factor invented**.
- Preferred robust configuration: **none supported by current evidence**.
- Immediate next control: O74 / X-B76 / X-A84, as a baseline to reproduce rather than a recommendation.

## Files

1. `OIIS_Factor_DOE_Protocol.docx` — complete governed DOE protocol and current-evidence review.
2. `OIIS_Factor_DOE_Workbook.xlsx` — source inventory, factor catalogue, levels, constraints, phases, responses, regimes, folds, scoring, Pareto rules, risks and QA.
3. `OIIS_DOE_Run_Matrix.csv` — 147 pre-registered trials.
4. `OIIS_DOE_Experiment_Config.json` — machine-readable experiment configuration.
5. `OIIS_Factor_Analysis_Results.xlsx` — analysis of currently available legacy evidence and explicit blockers.
6. `OIIS_Trial_Ledger.csv` — immutable ledger of the supplied legacy threshold evidence.
7. `OIIS_Event_Level_Outcomes.csv` — event-level minute-profile outcomes available from the supplied bundle.
8. `OIIS_Robust_Configurations.json` — explicit `NONE_SUPPORTED_BY_CURRENT_EVIDENCE` decision and next controls.
9. `charts/` — eight decision-useful Matplotlib charts.
10. `OIIS_FACTOR_DOE_DELIVERY_SHA256SUMS.txt` — package file checksums.

## Material limitation

The delivery contains a complete experiment protocol, matrix, configuration and current-evidence review. It does not claim to have executed the new Stage 0–Stage 6 DOE against the actual repository and qualified 500-stock data. Component influence, regime effects and robust configurations remain pending baseline reproduction and event-level component-score generation.
