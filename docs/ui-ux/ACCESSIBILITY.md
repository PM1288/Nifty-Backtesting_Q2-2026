# Accessibility Standard

Target: WCAG 2.2 AA for the operational workspace.

- Native landmarks, links, buttons, labels and tables are retained.
- Keyboard focus uses a visible 2 px primary-blue outline.
- Mobile actions have a minimum 44 px target.
- Positive/negative/warning states use icons or labels in addition to colour.
- Text and semantic colours use the V2 contrast palette.
- Navigation drawer supports Escape and a labelled scrim.
- Reduced-motion preference suppresses non-essential transitions and animations.
- Data tables retain tabular semantics and contained horizontal scrolling.
- The layout must remain usable at 200% zoom and at 430 px width without document overflow.

Automated checks reduce risk but do not replace a keyboard and screen-reader audit. That manual audit remains a release checklist item.
